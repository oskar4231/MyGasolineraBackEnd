# Explicación de Paquetes Instalados

## Dependencias Principales

**axios**
Cliente HTTP para hacer peticiones externas.
Conecta con otras APIs o servicios web.
Promesas sencillas.

**bcryptjs**
Encripta contraseñas para seguridad.
Protege datos sensibles en base de datos.
Hashing seguro.

**cors**
Permite peticiones desde otros dominios.
Conecta frontend con backend sin bloqueos.
Control de acceso.

**dotenv**
Carga configuración desde archivo .env.
Oculta claves secretas y credenciales.
Variables de entorno.

**express**
Framework para crear el servidor web.
Maneja rutas, peticiones y respuestas HTTP.
Base del proyecto.

**jsonwebtoken**
Genera y verifica tokens de seguridad.
Mantiene la sesión del usuario autenticado.
Login seguro.

**multer**
Maneja la subida de archivos (fotos/docs).
Procesa formularios tipo multipart/form-data.
Gestión de uploads.

**mysql2**
Conector para base de datos MySQL.
Ejecuta consultas SQL desde Node.js.
Rápido y seguro.

**nodemailer**
Envía correos electrónicos desde el servidor.
Gestiona emails transaccionales y notificaciones.
Comunicación SMTP.

**uuid**
Genera IDs únicos e irrepetibles.
Etiqueta archivos o registros sin duplicados.
Identificadores globales.

**winston**
Sistema de registro de logs (errores/info).
Guarda historial de lo que pasa.
Auditoría y debug.

## Dependencias de Desarrollo

**jest**
Herramienta para ejecutar pruebas automáticas.
Valida que el código funcione bien.
Test runner.

**supertest**
Prueba los endpoints HTTP del servidor.
Simula peticiones reales para testear.
Tests de integración.

**@types/jest**
Ayuda al editor a entender Jest.
Mejora el autocompletado de código.
Tipos de datos.
